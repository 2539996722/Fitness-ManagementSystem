⚠️ 安全提示
  • API Key 存储在 system_configs 表中，权限校验仅 admin。
  • 前端展示永远脱敏（仅末尾 4 位）。
  • 保存后客户端缓存会立即失效，下一次 AI 调用将使用新配置。
  • 如果 LLM 调用失败，C 端用户会看到兜底提示而非崩溃。
  • 建议生产环境结合密钥管理服务（KMS），不要把真实 key 直接写在 .env 中。
